## Контракт данных (делает агент «Админка», остальные только потребляют)
Все composables возвращают `ComputedRef` из `useEditableList(key, defaults)`:
- `useProjects()` → `{ projects, getBySlug, projectsList }`, где `projects` — computed, а `projectsList` — статичный fallback для обратной совместимости. У каждого проекта поля: `year`, `capacity`, `category`, `isKey` (bool, «ключевой объект»), `volume` (объём сточных вод, текст), `quality` (качество очистки, текст). Категории: `Коммунальное хозяйство` | `Мясопереработка` | `Молочные предприятия` | `Локальные очистные сооружения`.
- `useRegistry()` → `{ registry }` — локальные объекты (реестр). Поля как в `projectRegistry` + `year`. Категории те же четыре.
- `useTimeline()` → `{ timeline }`: `[{ year, title, text }]`. Блок «Путь компании».
- `useMediaCenter()` → `{ media }`: `[{ title, desc, kind: 'video'|'presentation', file, poster, duration }]`.
- `useNews()` → `{ news }`: прежние поля + `image`.
- `useEquipment()` → прежнее API + `equipment` (computed), где у позиции можно переопределить `photo` и `desc`.
