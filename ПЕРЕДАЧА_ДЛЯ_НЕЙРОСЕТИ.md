# Передача работ по сайту ESP — для следующего исполнителя (ИИ или человека)

Обновлено: 26.09.2026. Читать целиком перед любыми действиями.

## 1. Что это за проект

- Сайт компании ООО «ЭкоСервисПроект» (ESP) — очистка сточных вод, Беларусь.
- Nuxt 3 + Tailwind, хостинг Vercel. Контент частично из админки
  (`/admin`, данные в Vercel Blob, дефолты — `content/defaults/*.json`).
- Репозиторий: `github.com/Artemewww/esp-website`.
- Основной сайт: **https://esp-websitetest.vercel.app** (Vercel-проект
  `esp-websitetest`). Есть второй проект `esp-website` — это НЕ он.

### 4.3 Главная, блок 1 «Цифровой двойник» — ЗАКАЗЧИК СКАЗАЛ ОСТАВИТЬ КАК ЕСТЬ
`components/home/TechShowcase.vue`, картинки `public/images/digital-twin/cut/`.
Скролл-сцена, 5 этапов (логика заказчика «как объект появляется на местности
от А до Я»):
1. **Старые сооружения** — `stage-00-old.webp`: участок у реки, советские
   прямоугольные отстойники, поля фильтрации, розовые пруды.
2. **Лидарное сканирование** — `stage-01-lidar.webp` (плотное радужное облако

3. **Проектирование** — `stage-02-design.webp`: линии новой станции поверх

4. **Стройка** — `stage-03-build.webp`: новая станция, часть старых прудов ещё

5. **Запуск** — `stage-04-result.webp`: рекультивация, лес; точки-подсказки.

Кадры 1, 2, 3, 4 собраны программно (Python/PIL) из рендера
`stage-03.1.png` — генератора картинок не было. Если появятся
фотореалистичные рендеры — просто заменить файлы (геометрия участка та же,
1536×1024, углы ромба в `CORNERS` в компоненте).

## 6. Как проверять

```
npm ci && npx nuxt build && PORT=3000 node .output/server/index.mjs
```
Скролл-блоки удобно проверять скриншотами Playwright (Chromium установлен).
Блоки sticky: прокручивать `window.scrollTo`, а в CSS отключить
`scroll-behavior: smooth`. Подробнее о граблях — `HANDOFF.md`.
